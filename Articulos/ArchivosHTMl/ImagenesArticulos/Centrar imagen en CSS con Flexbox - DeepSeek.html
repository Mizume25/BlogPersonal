Para centrar la imagen en la página, puedes usar varios métodos. Te muestro los más efectivos:

Opción 1: Usando Flexbox (Recomendado)

css
body {
    background-image: url("../Index/Fondo/Fondo2.jpg");
    display: flex;
    justify-content: center;
    align-items: center;
    min-height: 100vh;
    margin: 0;
}

.profile img {
    width: 180px;
    height: 196px;
    border-radius: 50%;
    margin-bottom: 15px;
    border: 3px solid #C4A484;
    transition: transform 0.3s ease, box-shadow 0.3s ease; 
    cursor: pointer; 
}

Opción 2: Centrando solo la sección

css
body {
    background-image: url("../Index/Fondo/Fondo2.jpg");
    margin: 0;
    min-height: 100vh;
}

section {
    display: flex;
    justify-content: center;
    align-items: center;
    min-height: 100vh;
}

.profile img {
    width: 180px;
    height: 196px;
    border-radius: 50%;
    margin-bottom: 15px;
    border: 3px solid #C4A484;
    transition: transform 0.3s ease, box-shadow 0.3s ease; 
    cursor: pointer; 
}

Opción 3: Usando Grid

css
body {
    background-image: url("../Index/Fondo/Fondo2.jpg");
    display: grid;
    place-items: center;
    min-height: 100vh;
    margin: 0;
}

.profile img {
    width: 180px;
    height: 196px;
    border-radius: 50%;
    margin-bottom: 15px;
    border: 3px solid #C4A484;
    transition: transform 0.3s ease, box-shadow 0.3s ease; 
    cursor: pointer; 
}

Opción 4: Método tradicional con margin

css
body {
    background-image: url("../Index/Fondo/Fondo2.jpg");
    margin: 0;
    min-height: 100vh;
}

.profile {
    text-align: center;
    position: absolute;
    top: 50%;
    left: 50%;
    transform: translate(-50%, -50%);
}

.profile img {
    width: 180px;
    height: 196px;
    border-radius: 50%;
    margin-bottom: 15px;
    border: 3px solid #C4A484;
    transition: transform 0.3s ease, box-shadow 0.3s ease; 
    cursor: pointer; 
}

Recomiendo la Opción 1 (Flexbox) porque es más moderna, simple y responsive. El min-height: 100vh asegura que el cuerpo ocupe al menos toda la altura de la ventana, y justify-content: center y align-items: center centran el contenido tanto horizontal como verticalmente.

Explicación de grid-template-columns: 1fr 3fr 1fr;

Esta sentencia define tres columnas en un contenedor Grid CSS con proporciones específicas:

Desglose detallado:

css
.container {
    display: grid;
    grid-template-columns: 1fr 3fr 1fr;
}

¿Qué significa cada parte?

  • 1fr - Primera columna: ocupa 1 fracción del espacio disponible

  • 3fr - Segunda columna: ocupa 3 fracciones del espacio disponible

  • 1fr - Tercera columna: ocupa 1 fracción del espacio disponible

Visualización del resultado:

text
| Columna 1 |     Columna 2     | Columna 3 |
|  1 parte  |     3 partes      |  1 parte  |
|   20%     |       60%         |    20%    |

Ejemplo práctico:

html
<!DOCTYPE html>
<html lang="es">
<head>
    <style>
        .grid-container {
            display: grid;
            grid-template-columns: 1fr 3fr 1fr;
            gap: 10px;
            height: 200px;
            background: #f0f0f0;
            padding: 10px;
        }

        .columna {
            padding: 20px;
            border-radius: 5px;
            text-align: center;
            color: white;
            font-weight: bold;
        }

    </div>

Características importantes:

  1. Unidades fr (fracciones): Distribuyen el espacio sobrante después de asignar tamaños fijos

  2. Responsive: Se adapta automáticamente al tamaño del contenedor

  3. Proporcional: Mantiene siempre la relación 1:3:1 sin importar el tamaño de pantalla

Casos de uso comunes:

  • Layout principal: Sidebar - Contenido - Sidebar

  • Paneles de control: Menú - Área principal - Información

  • Diseños editoriales: Margen - Texto - Margen

Sentencias de Padding en CSS

Sintaxis Básica:

css
padding: valor;

Diferentes Formas de Usar Padding:

1. Padding Uniforme (mismo en los 4 lados)

css
padding: 20px;

2. Padding Vertical y Horizontal

css
padding: 10px 20px;  /* arriba/abajo: 10px, izquierda/derecha: 20px */

3. Padding Individual por Lados

css
padding: 10px 15px 20px 25px; /* arriba, derecha, abajo, izquierda */

4. Padding con Lados Específicos

css
padding-top: 10px;
padding-right: 15px;
padding-bottom: 20px;
padding-left: 25px;
